# VECTRAL - Premium AI Automation Agency Website

## 🎨 Overview

A **cinematic, motion-graphics-focused** website for VECTRAL AI Automation Agency, built with cutting-edge animations, real images, and a premium white/red color scheme. Every element is animated to create an immersive, professional experience perfect for client presentations.

---

## ✨ Key Features

### 🎬 Motion Graphics & Animations
- **Page Transitions**: Smooth Framer Motion transitions between all pages
- **Scroll Animations**: Elements animate in as you scroll (fade, slide, scale)
- **Hover Effects**: Every button, card, and icon has interactive hover animations
- **Parallax Effects**: Images move at different speeds for depth
- **Text Animations**: Word-by-word reveals, letter animations
- **Floating Elements**: Subtle floating animations for visual interest
- **Magnetic Buttons**: Buttons that respond to cursor proximity
- **Animated Logo**: Custom SVG logo with path drawing animations

### 🖼️ Real Images
- **Hero Section**: Cinematic AI technology background image
- **About Section**: Professional technology imagery
- **Services Section**: Abstract automation visuals
- **Case Studies**: Real dashboard and business imagery
- All images are high-quality, professional stock photos

### 🎨 Design System
- **Primary Color**: Red (#DC2626) - Bold, energetic, professional
- **Secondary**: White (#FFFFFF) - Clean, minimal, premium
- **Accent**: Black (#000000) - Strong contrast, editorial feel
- **Typography**: Space Grotesk (display) + Inter (body)
- **Spacing**: Generous whitespace for premium feel

### 📱 Fully Responsive
- Mobile-first design
- Optimized for all screen sizes
- Touch-friendly interactions
- Fast loading on mobile devices

## 🚀 Technical Stack

- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Routing**: React Router DOM (Hash Router)
- **Fonts**: Google Fonts (Space Grotesk + Inter)
- **Images**: Unsplash (high-quality stock photos)

---

## 🎬 Animation Techniques Used

1. **Scroll-triggered animations** - Elements animate when they enter viewport
2. **Stagger animations** - Child elements animate in sequence
3. **Parallax scrolling** - Images move at different speeds
4. **Text reveals** - Word-by-word and letter-by-letter animations
5. **Hover states** - Scale, rotate, color changes on hover
6. **Path animations** - SVG paths draw themselves
7. **Floating elements** - Subtle up/down motion
8. **Gradient animations** - Moving gradient backgrounds
9. **Magnetic buttons** - Buttons respond to cursor
10. **Page transitions** - Smooth enter/exit between pages
