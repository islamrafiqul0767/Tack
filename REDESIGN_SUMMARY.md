# VECTRAL AI - Hostinger-Inspired Website Redesign

## 📋 Executive Summary

VECTRAL AI ওয়েবসাইটটি Hostinger.com থেকে অনুপ্রাণিত হয়ে সম্পূর্ণ পুনর্ডিজাইন করা হয়েছে। ডিজাইনটি VECTRAL-এর নিজস্ব ব্র্যান্ড আইডেন্টিটি (লাল #DC2626, Space Grotesk + Inter typography) বজায় রেখে Hostinger-এর best practices প্রয়োগ করেছে।

---

## 🔍 Hostinger Research & Analysis

### Key Design Patterns Identified:

1. **Hero Section**
   - Clear, benefit-focused headline
   - Strong primary CTA with secondary option
   - Trust indicators below CTAs
   - Subtle background animations

2. **Navigation**
   - Sticky header with blur effect
   - Clean, minimal links
   - Prominent CTA button
   - Mobile-first responsive menu

3. **Service Presentation**
   - Icon-based cards with clear hierarchy
   - Feature lists with checkmarks
   - Hover effects for interactivity
   - Grid layout for easy scanning

4. **Pricing/Plans**
   - Clear plan cards with feature comparison
   - Highlighted recommended plan
   - Billing period selector
   - Feature checklists

5. **Trust Indicators**
   - Customer testimonials
   - Statistics/metrics
   - Security badges
   - Money-back guarantees

6. **FAQ Section**
   - Expandable accordion
   - Clear question/answer hierarchy
   - Search functionality

7. **Footer**
   - Multi-column layout
   - Organized link categories
   - Social media links
   - Legal links

8. **Animations**
   - Smooth page transitions
   - Scroll-triggered reveals
   - Hover effects on cards
   - Subtle parallax effects

## 🎨 Visual Design Highlights

### Color System
```css
--color-brand: #DC2626 (Primary Red)
--color-brand-light: #EF4444
--color-brand-dark: #991B1B
--color-ink: #000000 (Black)
--color-ink-muted: #525252 (Gray)
--color-surface: #fafafa (Light Gray)
--color-border: #e5e5e5
```

### Typography Scale
```css
Hero: clamp(2.75rem, 8vw, 7rem)
H1: 4xl - 7xl (responsive)
H2: 3xl - 6xl (responsive)
Body: base - xl (responsive)
Small: sm (14px)
```

### Spacing System
```css
Section padding: py-24 lg:py-32
Container max-width: max-w-7xl (1280px)
Grid gaps: gap-6 to gap-16
Card padding: p-6 to p-10
```

### Border Radius
```css
Small: rounded-lg (8px)
Medium: rounded-xl (12px)
Large: rounded-2xl (16px)
Full: rounded-full (9999px)
```
